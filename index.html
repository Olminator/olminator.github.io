How It Works

1. Export from Outlook

In Microsoft Outlook for Mac, go to File > Export, select .olm format, and save your archive.

2. Drag to Olminator

Open Olminator and drag your .olm file into the app—or use Finder's "Open With."

3. Preview and Select

Review emails, calendars, contacts, and notes in the built-in viewer. Choose output formats like .mbox, .ics, .vcf, PDF, HTML, or CSV.

4. Convert and Import

One-click conversion. Import results directly into Apple apps or any compatible service.
